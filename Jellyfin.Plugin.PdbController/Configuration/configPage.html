PDB Controller

Holds a Kubernetes PodDisruptionBudget open while Jellyfin is busy, so a node drain or a cluster upgrade waits instead of interrupting it. This only affects evictions — it does not stop a rolling update or a scale‑to‑zero.

The PodDisruptionBudget to toggle. It must already exist — this plugin never creates or deletes one.
Leave empty to use the namespace this pod runs in.

Scheduled tasks

Hold the budget while any of these are running.

With this on, a task added later by a plugin or a server upgrade is covered automatically, and the individual choices below are kept for when you turn it back off.

Hidden tasks still run, and a long one is still worth protecting.

Streaming users

Hold the budget while any of these users is playing something. A client that is merely connected and idle does not count; a paused stream does.

Timing

How long to wait after the last stream or task ends before releasing, so a pause or a reconnect does not flap the budget.
A hold is broken after this long, with a warning in the log. Without a cap a wedged task or a session that was never reaped blocks node drains and upgrades indefinitely.
The backstop. Playback and task events are acted on immediately; this is what recovers the state if one of them is ever missed.
