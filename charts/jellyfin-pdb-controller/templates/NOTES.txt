Three things this chart cannot do for you:

1. Install it into Jellyfin's own namespace. The plugin reads the namespace out
   of its service account directory, and a Role only binds within one.

2. Mount the token. Several charts (bjw-s app-template among them) default the
   pod-level automountServiceAccountToken to false. The account existing is not
   enough -- with no token file the plugin logs once and stays idle:

     controllers.main.pod.automountServiceAccountToken: true

3. Keep your GitOps controller off spec.minAvailable. Under ArgoCD that is an
   ignoreDifferences entry *and* RespectIgnoreDifferences=true -- the first
   hides the diff, the second is what stops a sync writing over a live hold.

Check a hold with:

  kubectl get pdb -n {{ .Release.Namespace }} {{ .Values.pdbName }} \
    -o jsonpath='{.spec.minAvailable}{"\t"}{.metadata.annotations}'
